Upload Learning Records

Upload curated CSV or Excel files to update GenAI learning data for employees. Choose whether to replace the existing dataset or append a new batch of records.

Upload mode

Replace all data

Completely replaces the existing dataset with the uploaded file. Existing data is backed up before replacement.

Append new records

Adds new records to the current dataset. Exact duplicates are detected and skipped; existing data is preserved.

Select a CSV or XLSX file to upload Supported formats: CSV, XLSX • Maximum size: 2 GB

Upload summary

Data requirements & processing

  • Data preparation: Uploaded data is cleaned and standardised. Level values are mapped to “Level 0”, “Level 1”, “Level 2”, “Level 3”, or “NA”.
  • Required columns: Assessment_ID, Assessment Name, Name, Email, Employee_ID, Final Completion Date, Issuer, Level, Marks, Qualifier, Skill, Skill_ID, Valid_Till, Wipro_Function.
  • File formats: CSV and Excel (XLSX) files are supported.
  • File size limit: Maximum 2 GB per upload (stored in S3).
  • Backup: Current data is backed up before replace operations.
  • Duplicates: In append mode, records that match all key fields are treated as duplicates and skipped.
  • Invalid records: Rows with invalid or incomplete data are automatically flagged and excluded.
  • Cloud storage: Large files are uploaded directly to secure S3 storage, then processed asynchronously.
